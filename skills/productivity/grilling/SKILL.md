# Grilling

Challenge the plan's material assumptions, trade-offs and failure cases. Keep the interview
within the user's requested scope and depth; ordinary planning does not require this workflow.

Map which decisions depend on others. Look up available facts before asking the user, and
reuse decisions already settled. Investigate in the main session; delegate only when existing
user or project authorization covers it. Any authorized subagent starts with a fresh context.

Ask one focused question at a time through the harness's waiting question tool when available.
Give a brief recommendation and the meaningful alternatives. Wait on work that depends on the
answer; continue independent investigation when useful. Batch questions only when requested,
within the tool's limits, and never put dependent questions in the same batch.

Decide routine implementation details. Ask when missing intent materially affects the result;
do not turn every possible branch into a question. Respect a requested question or time limit.

Stop when the requested critique is complete or the user redirects the work. Briefly summarize
settled decisions and remaining uncertainties. Further action follows the authorization already
given; an interview alone does not authorize implementation or require a new approval ritual.
